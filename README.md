# Notenotes

Self-hosted система для личных и семейных данных: заметки, списки, документы,
файлы — с поиском по всему сразу, визуально или запросом на естественном языке.

- **Что строим** — [TZ.md](TZ.md)
- **Как работать с проектом** — [CLAUDE.md](CLAUDE.md)
- **Сервер и развёртывание** — [infra/README.md](infra/README.md)

## Состояние

| | |
|---|---|
| Инфраструктура | развёрнута, https://notenotes.metallcorn.online |
| Backend | работает: ядро (Фаза 1) + AI-ассистент с tool-calling, авто-теги, OCR, распознавание речи (Фаза 2, в процессе) |
| Frontend | работает: веб, устанавливаемое PWA |

## Структура

```
infra/     Ansible: хардненинг, Docker, шифрованный том, Caddy, Postgres, бэкапы
app/
  backend/     FastAPI
  frontend/    React (веб + Telegram Mini App)
TZ.md      техническое задание
```

## Быстрый старт

Обслуживание сервера:

```bash
cd infra
make help          # список команд
make unlock        # после каждой перезагрузки сервера
```

Код редактируется локально, а исполняется на VPS — локально ничего
устанавливать не нужно. Правила и ограничения — в [CLAUDE.md](CLAUDE.md).
